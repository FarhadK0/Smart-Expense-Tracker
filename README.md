#  Smart Expense Tracker

A full-stack web application that helps users **track, categorise, and visualise personal expenses** using a modern **MERN stack (MongoDB, Express, React, Node.js)** architecture.

---

##  Overview

The Smart Expense Tracker enables users to log daily expenses, assign categories, and view interactive charts for financial insights.  
Developed as my **final-year project** for the **BSc (Hons) Software Development** at **De Montfort University**.

---

## Features

-  **Expense CRUD Operations** – add, update, and delete transactions.  
-  **Category Management** – organise spending by category (Food, Travel, Utilities, etc.).  
-  **Analytics Dashboard** – dynamic charts showing monthly totals and category breakdowns.  
-  **User Authentication** – JWT-based login and registration (if implemented).  
-  **Responsive Design** – built with React and CSS for mobile-friendly performance.  
-  **RESTful API** – clean separation between client and server for scalability.
